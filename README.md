# yktools
## yktoolsについて
個人的に作ったゆく育プレイヤー向けの便利なやつ(仮)。  
サイト作るの苦手なんでそこんとこ  
たびたび更新する(予定)
## 機能一覧
### 無限ダンジョン・ボストラッカー
[ボストラッカー](https://yktool.github.io/boss_tracker)  
ボタンぽちぽちするだけで簡単！  
次のボスを確認できる！(警告付き)  
脳死で周回したい人向け。  
### 仮想厳選
[仮想厳選](https://yktool.github.io/Skill_Roll)   
ゆっくりを指定してスキルをサイト上で抽選できる!  
目安を知りたい方向け。
